# GPDK090 17-MOS OTA의 NM11 폭 변경 실측

출력 싱크의 상단 NMOS인 NM11의 총 폭을 10 µm에서 1.5 µm로 줄였다. 두 회로에서 길이는 0.25 µm, 배수와 핑거 수는 각각 1이다. 다른 16개 MOS의 치수와 단자 연결은 기준 회로와 같다. 저장·독립 재개방된 후보 DUT는 `2a8572534ea286d82563557d4c4754a7fbb9633528ea7b390cbfbe4f49347dfc`다. [변경 전 동작점과 후보 선택 근거](README.md#nm11-변경-근거와-검증-경과)

## DC 측정

VDD 1 V, VSS 0 V, 양쪽 입력 0.5 V, 출력 부하 1 pF, 27 °C, GPDK090 NN에서 측정했다. ADE 변수 `VBIASN`과 `VBIASP`는 두 실행에서 각각 0.320 V와 0.702 V였다. 공급 전류 부호는 전압원 양의 단자로 들어가는 방향이 양수이고, 전달 전력은 전원이 회로에 공급하는 방향이 양수다.

| 항목 | 기준 W 10 µm | 후보 W 1.5 µm | 후보 − 기준 |
| --- | ---: | ---: | ---: |
| 출력 전압 (mV) | 96.895449 | 178.896701 | +82.001252 |
| 공급 전류 (µA) | −107.250173 | −107.225772 | +0.024401 |
| 정적 전달 전력 (µW) | 107.250173 | 107.225772 | −0.024401 |

같은 입력 공통모드에서 출력이 아래 전원 레일로부터 82.001 mV 더 떨어졌다. 따라서 폭을 줄이면 DC 출력이 올라간다는 가설은 이 측정점에서 지지된다. 178.897 mV는 여전히 두 입력의 공통모드인 500 mV보다 낮다. 전달 전력의 감소량은 약 24.4 nW였다.

기준 DC 작업은 `74e4610f-712b-4a2d-85b5-f891c10aaeac`, 실제 입력 SHA-256은 `948c3ece63248839651dc1d0a54c94eaf92090e97a8a36ca62be827fa22a60cc`다. 후보 DC 작업은 `c2e8161f-a775-4471-832e-ebfa79cbf649`, 실제 입력 SHA-256은 `972e04ed9acd7105b37eb93c56f85001b725fa442c1176fe6025403a3b02c3b9`다.

## 차동 AC 측정

각 주파수에서 실제 복소 출력 전압을 두 입력의 복소 전압 차이로 나눴다. 두 회로 모두 `inp`는 +0.5 V, `inn`은 −0.5 V로 차동 입력은 1 V였다. 1 Hz–1 GHz를 decade당 16점으로 읽어 각 회로에서 145점을 확보했다. 아래 교차 주파수는 첫 하강 구간에서 로그 주파수에 대해 이득(dB)을 선형 보간했다.

| 항목 | 기준 W 10 µm | 후보 W 1.5 µm | 후보 − 기준 |
| --- | ---: | ---: | ---: |
| 1 Hz 이득 (V/V) | 84.5015 | 230.3622 | +145.8607 |
| 1 Hz 이득 (dB) | 38.5373 | 47.2482 | +8.7109 |
| 10 Hz 이득 (dB) | 38.5373 | 47.2482 | +8.7109 |
| 1 Hz 이득 기준 −3 dB 대역폭 (kHz) | 465.727 | 418.043 | −47.684 |
| 0 dB 교차 주파수 (MHz) | 29.0959 | 35.1088 | +6.0129 |

후보의 −3 dB 교차를 둘러싼 실제 표본 주파수는 365.174–421.697 kHz, 0 dB 교차를 둘러싼 표본은 31.6228–36.5174 MHz였다. 이 측정점에서는 저주파 이득과 0 dB 교차 주파수가 높아졌고, 각 회로의 저주파 이득을 기준으로 한 대역폭은 좁아졌다. 위상여유를 측정하려면 별도의 루프 이득 구성이 필요하다.

기준 AC 작업은 `48b4d074-6a2d-428b-b409-87df84dc0d46`, 후보 AC 작업은 `feb0ac0f-8e00-4322-b09a-d9913c906af9`다. 후보의 실제 입력 SHA-256은 `66c7d368bddab960872c9e3877ef4fe4100d6acb2cd76dacb644d2d9b9b07559`다.

## 17개 소자의 동작점

각 회로의 원래 DC 결과에서 17개 소자의 `id`, `gm`, `gds`, `vgs`, `vds`, `vdsat`, `region`을 읽었다. 기준과 후보 모두 119개 값이 있었고, PMOS에도 원래 측정 부호를 유지했다. CSV에는 각 값의 단위, 기준값, 후보값과 차이를 담았다. `region`은 모델 분류 코드여서 원래 코드 두 개를 기록하고 산술 차이는 비웠다. [전체 동작점 119개](ota17-nm11-operating-points.csv)

| 소자·항목 | 기준 W 10 µm | 후보 W 1.5 µm |
| --- | ---: | ---: |
| NM11 드레인 전류 (µA) | +26.9037 | +26.8945 |
| NM11 VDS (mV) | 10.935 | 93.025 |
| NM11 VDSAT (mV) | 185.652 | 189.612 |
| NM11 gm (mS) | 0.137980 | 0.163965 |
| NM11 gds (mS) | 2.385253 | 0.198138 |
| PM6 드레인 전류 (µA) | −26.9201 | −26.8946 |

출력 가지의 전류 크기는 약 26.9 µA를 유지했다. 폭을 줄인 NM11에 걸리는 VDS가 약 82.09 mV 증가하고 gds는 기존 값의 약 8.3%로 줄었다. 이는 같은 가지 전류에서 출력 전압이 올라간 관측과 일치한다. 후보의 VDS도 모델이 보고한 VDSAT보다 작았다. 이 한 바이어스점에서 출력 전압·이득과 대역폭의 변화를 확인했으며, 출력 스윙 범위와 최적 폭은 별도로 측정해야 한다.

후보 동작점 조회 `fec13784-e25e-4d15-8e88-1e6bcca75ae3`는 원래 후보 DC 결과의 PSF `4c47303863775bec80eea15d276396eb5d13b4ada3e13350a3251abc1c936df5`를 한 번 읽었다. 원본 출력 SHA-256은 `9b1a736c2b4ef8face6d751b03357c864326306b8bab73a5f78fce4dd1406813`이다. 후보 DC와 AC는 각각 Spectre 1회로 완료했다. 전체 과정에서 OCEAN은 승인된 20회 중 20회, Spectre는 4회 중 4회를 사용했다.
